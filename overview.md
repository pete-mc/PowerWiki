# PowerWiki

PowerWiki adds a project-level **Power Wiki** menu item for viewing and editing Azure DevOps Wiki content with a modern Markdown and Mermaid rendering pipeline.

The extension is in early development. It is intended to keep Azure DevOps Wiki repositories as the source of truth while improving the wiki reading, editing, preview, and diagram rendering experience.

PowerWiki is an alternate experience. It does not remove or hide the standard Azure DevOps Wiki, so users can choose either the default Wiki or Power Wiki.
